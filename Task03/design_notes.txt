TASK A3 – POINTER DESIGN

Let stock[8] occupy consecutive int elements and p=&stock[0]. p+3 points to stock[3]; *(p+3) reads stock[3]; p[3] is equivalent to *(p+3); *p++ reads the current *p and then advances p by one int (post-increment binds to p).

Example memory diagram (illustrative addresses):
Address     Element     Value
0x1000      stock[0]      40  ← p initially
0x1004      stock[1]      25
0x1008      stock[2]      12
0x100C      stock[3]       8  ← p+3
...         ...           ...

int *lowest_stock(int *stock, size_t n) scans and returns &stock[min_index], or NULL for invalid/empty input. Caller can update *lowest_stock(...). Never return address of a local variable because its lifetime ends when the function returns, leaving a dangling pointer. Returning a pointer into caller-owned array is valid while that array remains alive and unmoved.

CLI design: bloodbank find O+; bloodbank issue A- 2; bloodbank register <id> <name> <group>. Validate argc before accessing argv, validate command and blood-group strings, parse numeric arguments with strtol and check errors/ranges, print usage and return nonzero on invalid input.

Index alternative: int idx=lowest_stock_index(stock,n); if(idx>=0) stock[idx] += amount. Both scans O(n) time/O(1) space. An index remains a numeric position but can become stale after insertion/reordering; a pointer becomes invalid if storage is reallocated. Recompute after any movement/reallocation.
