TASK A2 – RECURSIVE DESIGN

Digital root pseudocode:
DIGITAL_ROOT(n):
  IF n < 10 RETURN n
  sum ← 0
  WHILE n > 0: sum ← sum + (n MOD 10); n ← n DIV 10
  RETURN DIGITAL_ROOT(sum)
Base case: one digit (0–9). Recursive case: recurse on the sum of decimal digits. For d digits, time O(d) and recursive stack O(log d) in the worst digit-sum chain (each sum is smaller; the number of recursive rounds is bounded by repeated digit reduction).

Halving power pseudocode:
POWER(base,n):
  IF n = 0 RETURN 1
  half ← POWER(base, n DIV 2)
  IF n MOD 2 = 0 RETURN half × half
  ELSE RETURN base × half × half
Base case n=0; one recursive call per level. Time O(log n), stack O(log n). Linear recursive power has T(n)=T(n−1)+O(1), O(n) time and O(n) stack.

Example trace: POWER(2,10) → POWER(2,5) → POWER(2,2) → POWER(2,1) → POWER(2,0); unwind values 1,2,4,32,1024. Deepest stack contains arguments 10,5,2,1,0.

Missing base case causes unbounded calls until stack exhaustion/undefined failure. Prefer iteration for simple repeated work or when input depth may be large. Iterative digital root by digit summation is O(d) time/O(1) space; digital-root formula for positive n is O(1): n==0 ? 0 : 1+(n-1)%9.
