TASK A4 – DYNAMIC MEMORY DESIGN

Growable array fields: Donor *data; size_t size, capacity. Start capacity 0. Before append, if size==capacity choose new_capacity = capacity ? capacity*2 : 2. Check overflow before multiplication. Store realloc result in temporary pointer; if NULL, retain old data/capacity and report failure. On success assign data=temp and capacity=new_capacity, then append and increment size. Amortized append O(1), occasional resize O(n), total O(n) for n appends; capacity is less than 2n after growth, with less than capacity-size unused slots.

Fixed +10 strategy: realloc on each 10-record boundary. Repeated copying can total O(n²) in the worst case; doubling gives O(n) total copied elements. Fixed growth wastes at most 9 slots; doubling can leave nearly half the allocated capacity unused immediately after growth.

Memory errors:
- Leak: overwrite list.data with realloc result directly; if realloc fails old allocation is lost. Use temporary pointer and free list.data at shutdown.
- Dangling pointer: retain pointer to an element after realloc moves the block. Recompute element addresses after growth.
- Double free: free list.data in two cleanup paths. Set pointer NULL after free and centralize ownership/cleanup.
